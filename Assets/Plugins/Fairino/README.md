# FAIRINO C# SDK

이 폴더에는 FAIRINO 로봇 C# SDK DLL을 배치합니다.

## 다운로드

1. GitHub 또는 공식 다운로드 허브에서 FAIRINO C# SDK를 다운로드합니다.
2. 다음 DLL을 이 폴더에 복사합니다.
   - `libfairino.dll`
   - `CookComputing.XmlRpcV2.dll`
3. Unity Editor를 재시작합니다.

## 현재 템플릿 범위

이 템플릿은 `read-only live smoke`만 포함합니다.

- `Connect`
- `GetVersion`
- `ReadState`
- `Disconnect`

실제 로봇 motion command는 아직 이 템플릿에 포함하지 않습니다.
